# Die Tagen (The Day)
- <u>der</u> **Montag** : *Monday* ^montag
- <u>der</u> **Dienstag** : *Tuesday* ^deinstag
- <u>der</u> **Mittwoch** : *Wednesday* ^mittwoch
- <u>der</u> **Donnerstag** : *Thursday* ^donnerstag
- <u>der</u> **Freitag** : *Friday* ^freitag
- <u>der</u> **Samstag** : *Saturday* (**Wochenende** - *Weekend*) ^samstag
- <u>der</u> **Sonntag** : *Sunday* (**Wochenende** - *Weekend* ^sonntag
## Questions related to days
- **Vorgestern war ...........**
	- *day before yesterday was ..........*
- **Gestern war ..........**
	- *Yesterday was ..........*
- **Heute ist ...........**
	- *Today is ...........*
- **Morgen ist ..........**
	- *Tomorrow is .........*
- **Übermorgen ist ...........**
	- *Day after tomorrow is ..........*

# Sentence Formation
- **am + Tag/Datum/Tageszeit** 
	- *on + (day/date/season)*
- **um + Uhrzeit** 
	- *at (time)*
- **Im + Jahr/Monat** 
	- *in + (Year/Month)*
